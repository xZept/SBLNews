# Idea Research: Direct Search & Ask AI Flow and Structured AI Output

- **Created**: 2026-11-28T23:31:00+08:00
- **Evidence confidence (overall)**: high

## Users & Demand

- **Direct user/owner usability complaint on three concrete friction points**: The intake report identifies three specific issues observed while using `/` and `/search`: (1) the homepage search bar looks like a text input (`"Search literature..."`) but acts as a link button that redirects to `/search`; (2) on `/search`, `"Ask AI"` behaves as a mode-toggle button that merely reveals/renames the `"Synthesize"` submit button instead of directly triggering AI synthesis; and (3) AI synthesis outputs render messy raw `** **` markdown markers instead of a clean structured presentation. — [source: .specify/assessments/search-improvement/intake.md#L10] (confidence: high, cited)
- **Codebase confirms the homepage "fake search bar" affordance mismatch**: On `/`, `FilterBar` renders a `<Link href="/search">` styled as a 75%-width (`sm:col-span-3`) input-like box with a left-aligned `<Search>` icon and placeholder-style label `"Search literature..."`. Users clicking it expecting to type a query on `/` are immediately navigated to `/search`, while clicking the adjacent 25%-width `"Ask AI"` button toggles open a separate second row containing an `<Input id="feed-ask-ai-q">` and a `"Synthesize on /search"` submit button. — [source: web/src/components/feed/filter-bar.tsx#L136-L200] (confidence: high, cited)
- **Codebase confirms the two-step "Ask AI" → "Synthesize" interaction on `/search`**: In `AiSearchWorkspace`, the `"Ask AI"` button (`type="button"`) only toggles `aiActive` state (`setAiActive((prev) => !prev)`), which changes the adjacent submit button's label from `"Search"` to `"Synthesize"` and triggers a `GET /api/ai-search` quota lookup. A user who types a question on `/search` and clicks `"Ask AI"` does not trigger synthesis; they must subsequently click the `"Synthesize"` button. — [source: web/src/components/search/ai-search-workspace.tsx#L438-L470] (confidence: high, cited)
- **Codebase confirms raw `** **` markdown artifacts and collapsed formatting in `AiSynthesisPanel`**: `AI_SYNTHESIS_SYSTEM_PROMPT` instructs the model to return `"2-4 short paragraphs or bullet points, under 350 words"`, and the API stores/streams the text as `answerMarkdown`. However, `renderProseWithCitations` in `AiSynthesisPanel` only splits text on double newlines (`/\n{2,}/`) into `<p>` blocks and replaces `[S1]..[S5]` tokens with `<Link>` badges—it contains no parser or sanitizer for Markdown bold (`**...**`), headings, or bullet lists (`- ` / `* `), nor does the prompt enforce fixed structured sections. Consequently, literal `** **` asterisks and unformatted list items render verbatim in the UI. — [source: web/src/lib/ai-search/context-builder.ts#L37-L44, web/src/components/search/ai-synthesis-panel.tsx#L38-L90] (confidence: high, cited)
- **No external production analytics or multi-user telemetry in repository**: Demand signal comes from direct product owner testing following the `005-ai-literature-search` and `006-relocate-search-ask-ai` implementations rather than quantitative clickstream metrics. — [source: .specify/assessments/ai-search/research.md#L12, ASSUMPTION] (confidence: high, cited)

## Prior Art

- **Feature `005-ai-literature-search` (Unified Authenticated AI-Assisted Literature Search)**: Introduced `/api/ai-search`, the 3-tier failover chain (`Groq` -> `OpenRouter :free` -> `Gemini`), the `<2,000`-token context builder, `AiSearchWorkspace`, and `AiSynthesisPanel`. In `005`, `"Ask AI"` was modeled as an on/off mode toggle (`aiActive`) so that activating `"Ask AI"` on `/search` could display the user's remaining daily quota badge (`10/10 LEFT TODAY`) *before* submitting an uncached query (`FR-004`). — [source: specs/005-ai-literature-search/spec.md#L15, L100] (confidence: high, cited)
- **Feature `006-relocate-search-ask-ai` (Relocate Search Trigger and Ask AI Bar)**: Removed the `"Search"` link from `TopNav` (`web/src/components/layout/top-nav.tsx`) and relocated Search and Ask AI into a 75%/25% split row inside `FilterBar` on `/`. Because `006` specified a `"Search trigger button on the left taking up 3/4 (75%) of the container width"`, it was implemented as a wide `<Link href="/search">` with `"Search literature..."` text—inadvertently creating the visual appearance of a text input while behaving as a redirect link. — [source: specs/006-relocate-search-ask-ai/spec.md#L6, L70-L73, web/src/components/feed/filter-bar.tsx#L136-L158] (confidence: high, cited)
- **Existing tests locked to current `FilterBar` markup**: `web/tests/filter-bar.test.ts` explicitly asserts that `FilterBar` renders `<a href="/search">Search literature...</a>` and an `"Ask AI"` toggle button (`setAskAiOpen((prev) => !prev)`), meaning any UX change to `FilterBar` will require updating those unit assertions. — [source: web/tests/filter-bar.test.ts#L53-L148] (confidence: high, cited)
- **Structured metadata rendering in `StudyCard` and `/study/[id]`**: Elsewhere in SBL News (`web/src/components/study/metadata-breakdown.tsx`, `web/src/components/feed/study-card.tsx`), study information is presented in explicit, labeled Neo-Brutalist sections and cards (e.g., *Primary Outcome*, *Key Takeaway*, *Methodological Limitations*, evidence badges) rather than free-form unparsed markdown prose. — [source: web/src/components/search/ai-synthesis-panel.tsx#L187-L273, specs/001-sbl-news-mvp/spec.md] (confidence: high, cited)

## Market & Context

- **How users cope today**:
  - On `/`, a user wanting to search must either click the faux search bar (wait for `/search` to load, then focus the real input on `/search` and type) or click `"Ask AI"` to expand a hidden input row, type there, and click `"Synthesize on /search"`.
  - On `/search`, a user must type a query, click `"Ask AI"` to enter AI mode (or sign in if logged out), and then click `"Synthesize"` to run the AI synthesis.
  - When reading an AI synthesis, users must mentally filter out raw `** **` markdown delimiters and read dense paragraph blocks. — [source: web/src/components/feed/filter-bar.tsx#L136-L200, web/src/components/search/ai-search-workspace.tsx#L417-L499, web/src/components/search/ai-synthesis-panel.tsx#L38-L90] (confidence: high, cited)
- **Cost of doing nothing**:
  - Since `006-relocate-search-ask-ai` removed `"Search"` from `TopNav`, the 75%/25% row in `FilterBar` on `/` is now the *only* primary search entrypoint on the homepage. Leaving it as a fake input box frustrates every visitor attempting to type a search query from `/`.
  - On `/search`, the two-button `"Ask AI"` (toggle) + `"Synthesize"` (submit) pattern causes false starts where users click `"Ask AI"` expecting immediate synthesis and nothing happens beyond a button label change.
  - Raw `** **` markers in `AiSynthesisPanel` undermine the editorial polish and scientific credibility required by the Neo-Brutalist Sky Blue design system. — [source: specs/006-relocate-search-ask-ai/spec.md#L68, web/src/components/search/ai-search-workspace.tsx#L438-L470, .specify/memory/constitution.md#L53-L70, ASSUMPTION] (confidence: high, assumption)

## Data & Constraints

- **Constitution Principle I & III — Main Feed (`/`) ISR & Client Island Constraint**: `/` uses Incremental Static Regeneration (`export const revalidate = 3600` in `web/src/app/page.tsx#L6`). Replacing the fake search link on `/` with a real `<Input type="search">` inside `FilterBar` (a `"use client"` component) that submits directly to `/search?q=...` (for standard search) or `/search?ai=1&q=...` (for `"Ask AI"`) preserves static ISR on `/` with zero server cold starts. — [source: .specify/memory/constitution.md#L30, web/src/app/page.tsx#L6, web/src/components/feed/filter-bar.tsx#L1] (confidence: high, cited)
- **Constitution Principle I — Zero Extra UI / Markdown Library Dependencies**: Principle I (`Stack & Dependency Discipline`) prohibits introducing unapproved third-party npm packages without owner approval and a constitution amendment (`web/package.json` has no `react-markdown` or `marked` dependency). Structured AI synthesis rendering must therefore either use a lightweight built-in deterministic section/inline-token parser in TypeScript or structured prompt/section delimiters rather than heavy external Markdown libraries. — [source: .specify/memory/constitution.md#L37, web/package.json#L13-L26] (confidence: high, cited)
- **Constitution Principle IV & `005-ai-literature-search` — Logged-Out OAuth Gate & Daily Quota Protection**:
  - Standard search (`GET /search?q=...`) is 100% public and unlimited, whereas `/api/ai-search` requires authentication (`401 Unauthorized` when signed out) and enforces a daily per-user quota (`10` uncached syntheses/day for members, unlimited for admins).
  - If `"Ask AI"` becomes a direct action button (rather than a passive mode toggle), clicking `"Ask AI"` when signed out must still open `AskAiOAuthPrompt` (preserving the typed query and active filters) without calling `POST /api/ai-search`.
  - Automatically running AI synthesis on *every* standard search would burn a signed-in user's 10/day quota when they only wanted keyword/semantic study cards; keeping `"Search"` (standard search) and `"Ask AI"` (direct AI synthesis trigger) as two distinct direct submit actions on the same query input avoids accidental quota consumption while eliminating the extra toggle step. — [source: .specify/memory/constitution.md#L77, specs/005-ai-literature-search/spec.md#L15, L97-L108, web/src/components/search/ai-search-workspace.tsx#L125-L148, ASSUMPTION] (confidence: high, cited)
- **Shared Query-Answer Cache Compatibility (`public.ai_synthesis_cache`)**: Cached syntheses in Supabase store `answer_markdown text` (`answerMarkdown` in `/api/ai-search`) with a 7-day default TTL. Any structured AI output format must remain backward-compatible with `answer_markdown` text storage (e.g., deterministic labeled sections + inline formatting parser that strips/renders `**...**` and bullet lists cleanly for both newly generated and existing cached answers). — [source: web/src/app/api/ai-search/route.ts#L119-L130, L221-L232] (confidence: high, cited)

## Evidence Against the Idea

- **Pre-submit quota visibility tradeoff (`005` `FR-004`)**: In `005-ai-literature-search`, `FR-004` specified that activating `"Ask AI"` on `/search` displays the user's remaining daily quota badge (`e.g., 10/10 LEFT TODAY`) *before* submission. Because `/search/page.tsx` already hydrates `initialQuota` server-side for signed-in users (`web/src/app/search/page.tsx#L73-L79`), the quota badge can actually be shown on `/search` immediately whenever a user is signed in without needing an `"Ask AI"` toggle step—Wait: currently `AiSearchWorkspace` hides the badge behind `{aiActive && profile && quota && (...)}` (`web/src/components/search/ai-search-workspace.tsx#L472`). Removing the toggle requirement slightly alters `005` `FR-004`'s literal wording ("as soon as a signed-in user activates Ask AI... before submitting") unless the quota badge is always visible next to `"Ask AI"` for signed-in users on `/search`. — [source: specs/005-ai-literature-search/spec.md#L15, L100, web/src/app/search/page.tsx#L73-L79, web/src/components/search/ai-search-workspace.tsx#L472] (confidence: high, cited)
- **Submitting an empty query when clicking `"Ask AI"`**: If `"Ask AI"` directly triggers synthesis instead of opening an input or toggling a mode, a user might click `"Ask AI"` before typing a question into the search input (`query.trim().length < 3`). The UI will need a clear behavior for an empty/short input (e.g., focusing the search input and showing a prompt/validation hint rather than firing an invalid request). — [source: web/src/components/search/ai-search-workspace.tsx#L152-L160, web/src/lib/validations/ai-search.ts, ASSUMPTION] (confidence: medium, assumption)
- **Streaming compatibility with rigid formats (e.g. raw JSON vs. structured sections)**: `/api/ai-search` streams tokens progressively via SSE (`event: delta`) across 3 different free-tier providers (`Groq`, `OpenRouter :free`, `Gemini`). Requiring strict JSON output from the LLM would break progressive text streaming and risk JSON parse failures across free-tier models, whereas structured Markdown sections rendered by a deterministic client parser (handling headings, bullet points, bold spans, and `[S1]` citations) preserve progressive streaming and work across all 3 tiers. — [source: web/src/app/api/ai-search/route.ts#L214-L219, web/src/lib/ai-search/failover-client.ts#L244-L315, ASSUMPTION] (confidence: high, assumption)
