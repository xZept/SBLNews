## Idea (as captured)

> "The current UX for search seems confusing. At the homepage, the search appears to be a search bar but turns out to be a button that redirects to another page. Same goes for Ask AI on /search webpage which appears to be a button for opening the "synthesize" button which is the actual trigger for the search. I want this flow to be more direct. Plus, I want AI results to be more structured, not outputs that are messy and enclosed with ** **"

## Restated

Simplify the search and Ask AI user flows so users can enter and submit queries directly from the homepage and `/search` without intermediate redirect or reveal buttons. Additionally, present AI-generated search results in a structured format instead of raw markdown-style text containing `** **` emphasis markers.
